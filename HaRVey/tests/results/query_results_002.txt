Q02: Basic - CCC2 error code E1
================================================================================

Query Text:
--------------------------------------------------------------------------------
What does error code E1 mean on the CCC2 thermostat, and what are its likely causes?

Status: response_generated

Response:
--------------------------------------------------------------------------------
On the CCC2 thermostat, error code **E1** indicates a **loss of communication**. 

Depending on the specific situation, this can mean:
* **Loss of communication between the thermostat and all system power module boards**, which causes the system to shut down.
* **Loss of communication between the thermostat and an individual system power module board**. In this case, the LCD will display the error code and the zone number that lost communication; any additional zones that lose communication will also blink.

Likely causes include:
* Two power module DIP switches set to the same zone.
* Issues with the communication cable.
* 12 Volt DC power that is not clean (trying direct DC from a battery is suggested).
* Any of the above causing the Power Module to shut down.

---

Sources:
- CCC2-Diagnostic-Mode-With-Reset.pdf (page 2, Error Codes): E1 – Loss of communications
- CCC2-Operating-Instructions.pdf (page 10, LCD Error Code): E1 Loss of communication between the CCC 2 thermostat and all system power module boards.
