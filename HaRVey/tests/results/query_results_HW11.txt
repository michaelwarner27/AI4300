Q02: Basic - CCC2 error code E1
================================================================================

Query Text:
--------------------------------------------------------------------------------
What does error code E1 mean on the CCC2 thermostat, and what are its likely causes?

Status: response_generated

Response:
--------------------------------------------------------------------------------
On the CCC2 thermostat, error code E1 indicates a loss of communication.

Specifically, it can mean:
* **Loss of communication between the CCC 2 thermostat and all system power module boards**, which causes the system to shut down.
* **Loss of communication between the CCC 2 thermostat and an individual system power module board**. In this case, the LED will display error code E1 and the zone number that lost communication.

The likely causes include:
* Two power module DIP switches set to the same zone.
* Issues with the communication cable.
* 12 Volt DC that is not "clean" (it is suggested to try direct DC from a battery).
* Factors that cause the Power Module to shut down.

---

Sources:
- CCC2-Diagnostic-Mode-With-Reset.pdf (page 2): Error Codes 
ª E1 – Loss of communications 
ª Two power module DIP switches set as same zone. 
ª Communication cable. 
ª 12 Volt DC not clean, Try direct DC from battery. 
ª Causes Power Module to shut down
- CCC2-Operating-Instructions.pdf (page 10): E1 Loss of communication between the CCC 2 thermostat and all system power module boards. System will shut down.
E1 Loss of communication between the CCC 2 thermostat and an individual system power module board. The LED will display error code EI and the zone number that lost communication.
