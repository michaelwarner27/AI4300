To enter diagnostic mode on the CCC2 thermostat, follow these steps:

Q02: Basic - CCC2 error code E1
================================================================================

Query Text:
--------------------------------------------------------------------------------
What does error code E1 mean on the CCC2 thermostat, and what are its likely causes?

Status: response_generated

Response:
--------------------------------------------------------------------------------
On the CCC2 thermostat, error code E1 indicates a loss of communication. There are two specific scenarios described:

*   **Loss of communication between the CCC 2 thermostat and all system power module boards:** In this case, the system will shut down.
*   **Loss of communication between the CCC 2 thermostat and an individual system power module board:** The LED will display error code E1 and the zone number that lost communication. Any additional zones that lose communication will blink in addition to the current zone.

---

Sources:
- CCC2-Operating-Instructions.pdf (page 10, LCD Error Code): Error Code:\nE1 Loss of communication between the CCC 2 thermostat and all system power\nmodule boards. System will shut down.\nE1 Loss of communication between the CCC 2 thermostat and an individual system\npower module board. The LED will display error code EI and the zone num-\nber that lost communication. Any additional zones that loose communication will\nblink in addition to the current zone.
