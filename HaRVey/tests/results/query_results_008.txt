On the CCC2 thermostat, error code **E1** indicates a loss of communication. This can manifest in two ways:
* **System-wide:** Loss of communication between the CCC 2 thermostat and all system power module boards, which causes the system to shut down.
* **Individual Zone:** Loss of communication between the CCC 2 thermostat and an individual system power module board. In this case, the LED will display the E1 error code and the specific zone number that lost communication; other zones that lose communication will also blink.

**Likely causes include:**
* Two power module DIP switches are set to the same zone.
* Issues with the communication cable.
* Power issues (it is suggested to try direct DC from the battery).

* **08**: LCD shows Evaporator Coil Temperature (Or E5 if missing)
* **09**: LCD shows Outdoor Temperature (HP only, Or E4 if missing)
