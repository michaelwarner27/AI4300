On the CCC2 thermostat, error code E1 indicates a **loss of communication** between the thermostat and the system power module boards. Depending on the specific configuration, this can mean a loss of communication with all system power module boards (causing the system to shut down) or with an individual system power module board.

**Likely causes include:**
*   Two power module DIP switches are set to the same zone.
*   Issues with the communication cable.
*   The 12 Volt DC power is not clean (it is suggested to try direct DC from a battery).

---

On the CCC2 thermostat, error code E5 indicates that the **Freeze Sensor is Open or Out of Range**. 

When this error occurs, air conditioner and dehumidification operations are locked out, but heat pump, furnace, heat strip, and fan operations can continue to operate (though the display will show the last temperature set-point).
